# متجر وموقع أبو الجوخ 1925 | Abo El Goukh Bicycles Official Store

مشروع المتجر الإلكتروني الرسمي لشركة **أبو الجوخ** لتجارة الدراجات الهوائية في مصر (تأسس عام 1925)، بتصميم عصري فائق الفخامة والسرعة مستوحى من كبرى متاجر الدراجات العالمية (Trek & Canyon).

---

## 📁 هيكل المشروع (Project Architecture):
* `index.html`: الصفحة الرئيسية للمتجر (Hero فيديو إعلاني يوتيوب تفاعلي، تشريح هندسي، بانتو التصنيفات، الأسئلة الشائعة SEO، وفروع وسط البلد والتجمع والإسكندرية).
* `shop.html`: كتالوج العجل الكامل (55 عجلة أصلية، فلاتر فورية، بحث، حاسبة تقسيط فاليو لكل عجلة، سلة مشتريات منزلقة، ومودال المواصفات).
* `admin.html`: لوحة التحكم المجانية 100% لإدارة المنتجات وتعديل الأسعار وإضافة دراجات جديدة ورفع الصور من الموبايل.
* `abu_el_goukh_logo.png`: اللوجو الرسمي الأصلي للمتجر.
* `vercel.json`: إعدادات النشر على Vercel لعناوين الروابط النظيفة (Clean URLs) والكاش والحماية.

## 🚀 خطوات الرفع على GitHub والنشر الفوري على Vercel (خلال دقيقة واحدة):

### الخطوة 1: تهيئة المستودع ورفعه على GitHub
افتح موجه الأوامر (Terminal / Git Bash) داخل هذا المجلد (`abu_el_goukh_store`):
```bash
git init
git add .
git commit -m "Initial commit: Abu El Goukh flagship store with video hero and free admin"
git branch -M main
git remote add origin https://github.com/USERNAME/abu-el-goukh-store.git
git push -u origin main
```
*(استبدل USERNAME باسم حسابك على GitHub)*

---

### الخطوة 2: النشر على Vercel (مجاني 100% مدى الحياة):
1. ادخل على [Vercel.com](https://vercel.com) وسجل دخولك بحساب GitHub.
2. اضغط على **"Add New..."** ثم اختر **"Project"**.
3. اختر مستودع `abu-el-goukh-store` واضغط **"Import"**.
4. لا تغير أي إعدادات (اترك كل شيء افتراضياً) واضغط زر **"Deploy"**.
5. خلال 15 ثانية، سيكون موقعك حياً على الإنترنت برابط سريع جداً مثل:
   `https://abu-el-goukh-store.vercel.app`
