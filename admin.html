حماية لوحة التحكم المشفرة (Serverless Auth)

🛡️ النظام مؤمن بالكامل عبر خادم Vercel Serverless

تم إلغاء تخزين كلمات المرور كنص مكشوف في قاعدة البيانات لمنع أي تسريب. التحقق يتم الآن مشفراً ومحمياً ضد هجمات التخمين بتوقيع HMAC-SHA256.

كيفية تعديل بيانات الدخول:

لتغيير اسم المستخدم أو كلمة المرور الخاصة بالإدارة، يتم التعديل بأمان من لوحة Vercel:

ADMIN_USERNAME = your_username
ADMIN_PASSWORD = your_password
ADMIN_JWT_SECRET = your_secret_key

المسار: Vercel Dashboard ➔ Project Settings ➔ Environment Variables
