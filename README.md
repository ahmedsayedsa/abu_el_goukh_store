# متجر وموقع أبو الجوخ 1925 | Abo El Goukh Bicycles Official Flagship Store

المتجر الإلكتروني الرسمي لشركة **أبو الجوخ** لتجارة وتوزيع الدراجات الهوائية في مصر (تأسس عام 1925 - مئوية 100 عام)، بتصميم متطور فائق الفخامة والسرعة مستوحى من كبرى متاجر الدراجات العالمية (Trek & Canyon)، ومبني بأعلى معايير الأمان (Zero-Trust) وسرعة التحميل.

---

## 📁 هيكل صفحات المتجر وتجربة المستخدم (Storefront Pages):
* `index.html`: الصفحة الرئيسية للمتجر (Hero فيديو سينمائي، شريط مميزات الشحن والتجميع، تشريح هندسي، بانتو التصنيفات، شركاء التقسيط، الأسئلة الشائعة SEO، وزر واتساب العائم).
* `shop.html`: كتالوج الدراجات الكامل (67 عجلة أصلية، فلاتر فورية حسب الفئة والسعر، شارات المخزون اللحظية، حاسبة تقسيط فاليو، سلة منزلقة، ومودال المعاينة السريعة).
* `product.html`: صفحة استوديو المنتج التفاعلية (معرض صور متعدد الزوايا Studio Gallery، شارة المخزون اللحظي مع تنبيهات الندرة، مراجعات العملاء الموثقة، بيانات Schema.org JSON-LD لمحركات البحث، وزر الشراء السريع).
* `checkout.html`: صفحة الدفع الآمنة (التحقق السحابي الصارم من الأسعار والمخزون، تطبيق الكوبونات، تتبع السلات المتروكة تلقائياً، والربط مع بوابات الدفع الإلكتروني والدفع عند الاستلام).
* `track-order.html`: صفحة تتبع الشحنات والطلبات برقم الطلب ورقم الهاتف مع حماية صارمة ضد التخمين (Anti-Enumeration)، ومؤشر مراحل التجهيز والشحن، والدعم الفوري عبر واتساب.
* `about.html`: صفحة قصة وتاريخ أبو الجوخ (1925–2026) بمناسبة مئوية التأسيس، معايير الجودة، خدمات الصيانة، ومقر المعرض الرئيسي بجسر السويس.
* `returns-policy.html`: سياسة الاستبدال والاسترجاع والضمان المتوافقة بالكامل مع قانون حماية المستهلك المصري رقم 181 لسنة 2018 (حق المعاينة قبل الدفع، 14 يوماً للاسترجاع، 30 يوماً لعيوب الصناعة).
* `admin.html`: لوحة الإدارة والتحكم السحابية الشاملة والمشفرة بـ JWT.

## 🛡️ لوحة التحكم والإدارة (Admin Dashboard):
* **لوحة إحصائيات فورية (Live Stats Dashboard):**
  * إيرادات ومبيعات اليوم بالجنيه المصري وعدد الطلبات المسجلة.
  * عدد الطلبات قيد المراجعة والشحن.
  * عدد السلات المتروكة مع مؤشر الفرص البيعية.
  * إجمالي الموديلات والقطع الفعلية المتوفرة بالمخزن.
* **إدارة المنتجات والمخزون:**
  * إضافة وتعديل الدراجات، تحديد المخزون بدقة، شارات التميز (Badges)، ورفع صور متعددة لمعرض الأستوديو.
  * تعطيل الشراء التلقائي عند نفاد المخزون (`stock = 0`).
* **إدارة أكواد الخصم والكوبونات (Discount Codes Engine):**
  * إنشاء كوبونات بنسبة مئوية (مثل `GOUKH1925`) أو شحن مجاني (مثل `FREESHIP`).
  * تحديد الحد الأدنى للطلب وتفعيل/تعطيل أو حذف الكود سحابياً.
* **استرجاع السلات المتروكة (Abandoned Carts Recovery):**
  * التقاط رقم العميل ومحتويات السلة وقيمتها لحظياً.
  * زر **متابعة واتساب بنقرة واحدة** يفتح رسالة مخصصة ومهذبة لاستعادة البيع وتقديم الدعم الفني.
* **إدارة بوابات الدفع والـ APIs:**
  * تفعيل وتعديل مفاتيح الربط لبوابات Paymob و FawryPay و PayTabs و InstaPay و Cash on Delivery.
* **بيكسل الإعلانات والتتبع:**
  * إدارة Meta Pixel و TikTok Pixel و Google Tag Manager و Snapchat Pixel سحابياً.
* **فيديو الهيدر السحابي:**
  * تحديث رابط فيديو الواجهة والتحكم في الشفافية وسرعة العرض.

## 🔒 بنية الأمان والـ Backend السحابي (Serverless Architecture):
* **Zero Client Trust:** السيرفر لا يثق في أي سعر أو حسابات قادمة من العميل، ويتم احتساب المجموع وخصم الكوبونات وفحص توفر المخزون عبر `api/_verify-price.js`.
* **Stock Protection:** خصم المخزون تلقائياً عند اعتماد الطلب، ومنع شراء أي كميات تتجاوز المتوفر.
* **Anti-Enumeration:** حماية خصوصية العملاء في `api/orders.js` بإرجاع خطأ عام في حالة عدم تطابق رقم الهاتف مع رقم الطلب.
* **Secure Webhooks:**
  * التحقق من توقيع FawryPay وفقاً لمعايير فوري الرسمية (حساب HMAC-SHA256 على المعاملات المكتملة `NEW/PAID`).
  * التحقق من توقيعات Paymob و PayTabs.
* **Admin Authentication:** حماية كافة وظائف الإدارة عبر توكنات JWT المشفرة بتوقيع HMAC-SHA256 (`api/admin-auth.js`).

## ⚙️ متغيرات البيئة في Vercel (Environment Variables):
عند النشر على Vercel، يُنصح بضبط المتغيرات التالية في لوحة المشروع:
```env
# إدارة لوحة التحكم المشفرة
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your_secure_password
ADMIN_JWT_SECRET=your_jwt_secret_random_key_64_chars

# قاعدة البيانات السحابية (Firebase Realtime Database)
FIREBASE_DATABASE_URL=https://your-firebase-rtdb.firebaseio.com
FIREBASE_AUTH_SECRET=your_firebase_database_secret

# بوابات الدفع (تُدار أيضاً من لوحة التحكم)
PAYMOB_API_KEY=...
PAYMOB_HMAC=...
FAWRY_MERCHANT_CODE=...
FAWRY_SECURITY_KEY=...
PAYTABS_SERVER_KEY=...
```
