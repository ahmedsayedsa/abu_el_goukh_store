أدوات الكتالوج

الأدوات دي بتشتغل على قاعدة بيانات المتجر مباشرة (نفس اللي المتجر بيعرض منها). لازم تكون مسجل دخول لوحة التحكم في نفس المتصفح. عدد المنتجات حاليًا: ...

١) تعديل الأسعار بالنسبة %

مثال: سعر الصرف زاد — ارفع كل الأسعار ٥% مرة واحدة. التقريب بيخلي كل سعر ينتهي بـ٥٠ أو ١٠٠ (تقريب لفوق). قبل النشر هتنزل نسخة احتياطية تلقائيًا.

٢) أبلود منتجات كتير (استيراد)

ارفع ملف JSON (صيغة تصدير المتجر) أو CSV بالأعمدة: sku, name, price, category, cat_key, size, image, specs. الدمج بيحدّث المنتج بنفس الـSKU أو يضيفه جديد. الاستبدال الكامل بيستبدل الكتالوج كله بالملف.

٣) تصدير / نسخة احتياطية

تنزيل الكتالوج الحالي كله في ملف JSON واحد — ينفع نسخة احتياطية أو أساس لتعديل ورفع تاني.
